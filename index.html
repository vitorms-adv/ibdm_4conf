Fonte de Dados — Apps Script

O painel lê e grava direto na planilha através de um Web App do Apps Script (não mais CSV publicado). A senha de acesso é validada no servidor, nunca fica exposta neste código.

Atualização Automática

O valor padrão (AUTO_REFRESH_MS) também pode ser editado no código.

Como publicar no Google Sites

1. No Apps Script vinculado à planilha: Implantar → Nova implantação → Aplicativo da Web.
2. Copie a URL gerada e cole como APPS_SCRIPT_URL no início do código.
3. No Google Sites: Inserir → Incorporar → Cole o HTML completo.
4. Ao abrir o painel, informe a senha de acesso na tela de bloqueio.
